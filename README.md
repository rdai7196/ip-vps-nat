## NAT 机和独立IP，差的不只是一个地址

NAT 机型的服务器本身有内网地址，通过共享公网 IP + 端口映射对外服务。雨云的 NAT 机型一般开放 10 个端口（游戏云机型是 15 个），够跑一个测试环境、内网穿透或者游戏私服，但不够建站。

独立 IP 机型是你独享一个公网地址，区别集中在四件事上：

- **端口全开**。不是「多开几个」的问题，而是 80、443、25、SMTP 这些端口能不能用的问题。NAT 下想用 80/443 建站，基本行不通。
- **不被连坐**。共享 IP 意味着同 IP 上有人被打或者被拉黑，你的域名也跟着受影响。这是很多人换独立 IP 的直接原因。
- **防御独享**。共享型 IP 的高防是「共享 150G」这类口径，攻击打过来是整个 IP 段一起扛；独立 IP 在宿迁、十堰这类机房会独享该地区的高防。
- **业务侧识别**。跨境平台、社媒后台、流媒体风控都会看 IP 归属和数据中心属性，这也是为什么市面上出现了「原生 IP」「住宅 IP」这些细分品类——同样的机器，换个 IP 类型，价格能差好几倍。

顺带提一句：如果只是学习 Linux、做内网穿透、跑个小程序，NAT 机型没必要多花钱。

## 常见问题

**买了 NAT 机型之后还能加独立 IP 吗？**
可以，控制台里自助加购即可，单台云服务器最多加购 3 个独立 IP。加购后端口开放限制随之解除。

**独立 IP 会被别人用过的黑名单影响吗？**
会，但影响有限。雨云允许每周自助更换一次 IP，新 IP 随机分配，遇到被标记的地址可以换。反过来，如果你在做对 IP 纯净度敏感的跨境业务，换 IP 属于下策，一开始就该选原生或住宅类型。

**流量超了会停机吗？**
不会。流量型套餐用完后限速到 5Mbps，业务继续跑，买流量包可以恢复高速。

**能装 Windows 吗？**
可以，云服务器同时支持 Linux 和 Windows，也支持随系统预装宝塔、1Panel、Docker 等环境。

**退订有什么坑？**
7 天无理由退款退到雨云账户余额，每个账号 3 次机会；日付产品和试用产品不适用；已经用掉的优惠券和积分不会退回。
